01C++ console application

Student Expense Tracker

A clearer picture of where the money goes. A file-based tool for recording, finding, and understanding everyday student expenses.

C++File I/OSearch & filtering
  • Record, categorize, and retrieve expenses.
  • Search by description, category, date, amount, or ID.
  • Set budgets, edit records, and undo deletions.
  • Integer cents avoid floating-point money errors.
  • Validated input handles dates, amounts, and records.
  • File persistence includes backups for rewrites.

Built around a problem I experienced myself. Better expense visibility helped me reduce personal mindless spending by approximately $300 per month.
