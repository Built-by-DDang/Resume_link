01C++ / Record management

Student Expense Tracker

A console application I built to keep student expenses organized, searchable, and recoverable when records change.

C++File I/OValidationSearch & recovery
Problem
I wanted a reliable record of everyday spending that I could return to, search, and correct as my history grew.
Implementation
Description search lowercases the query and each record, then scans for a substring match. Matching record indexes are collected for display and totals.
Decision
Integer cents avoid floating-point money errors. Permanent IDs survive edits; rewrites use a temporary file and a backup before replacing the original.
Limitation
Search still scans the full history. For larger datasets, I’d add an index and automated tests for interrupted writes and recovery.

    02Electrical engineering / Browser narration

    EE 200 Narrated Study Guide

    An audio-first review of complex numbers and first-order differential equations, with worked steps and circuit applications alongside the narration.

    JavaScriptSpeech synthesisPlayback state
    Problem
    I wanted to work through EE 200 methods as spoken lessons while keeping the equations and written reasoning in view.
    Implementation
    Chapter text becomes a queue of speech segments. Playback highlights the current passage, and a generation token prevents old callbacks from advancing a new session.
    Decision
    I used browser speech synthesis and kept the transcript in the same HTML file, so the reader can move between listening, equations, and worked examples.
    Limitation
    Voices and pause behavior depend on the device. I’d strengthen long-sentence chunking and test playback cancellation across browsers.

    03Study software / Structured progress

    ASIAN 101 Study & Practice

    A browser-based study tool with 300 flashcards and 106 practice questions, organized by topic and recall status.

    HTML / JavaScriptJSONlocalStorage
    Problem
    I wanted to turn ASIAN 101 course material into questions I could answer from memory and revisit when I got stuck.
    Implementation
    Cards and questions live in separate JSON arrays with stable IDs. Progress is stored by ID in localStorage, independently of shuffled display order.
    Decision
    Revealing an answer does not mark it learned. I kept recall grading explicit and added topic, missed-item, and ungraded-item filters.
    Limitation
    Progress stays in one browser, and self-grading is subjective. I’d add spaced review scheduling and progress import/export.
